# 공공 API로 데이터 수집 & pandas DataFrame 만들기

> 공공데이터포털 API를 호출하고, JSON 응답에서 원하는 필드만 for문으로 추출해 DataFrame을 구성하는 전 과정을 다룹니다.

---

## 🛠 사용 기술

`Python` `requests` `pandas` `공공데이터포털 API`

---

## 📌 오늘 배운 핵심 3줄 요약

- 💡 `requests.get()`으로 공공 API를 호출하고 `res.json()`으로 파싱하면 응답이 dict 구조로 저장된다.
- 💡 `data['data']`는 측정 데이터가 담긴 **list of dicts** 구조 — for문으로 순회하면 각 row를 dict로 꺼낼 수 있다.
- 💡 `rows.append({'key': i['key']})` 패턴으로 원하는 컬럼만 인덱싱해서 DataFrame을 깔끔하게 만들 수 있다.

---

## 1️⃣ API 호출 & 응답 확인

공공데이터포털에서 **재비산먼지 측정 데이터** API를 활용했습니다.

```python
import requests
import pandas as pd

base_url = "https://api.odcloud.kr/api/15021888/v1/uddi:5b8bc25c-8415-4fb6-9ed3-f643de29fe3e?page=1&perPage=10"
service_key = "발급받은_인증키"

params = {
    "serviceKey": service_key,
    "pageNo": 1,
    "numOfRows": 10,
    "type": "json"
}

res = requests.get(base_url, params=params, timeout=10)

print("status_code:", res.status_code)   # 200 확인
print("request_url:", res.url)            # 최종 요청 URL 확인
print(res.text[:500])                     # 응답 앞부분 미리 보기
```

**✅ API 요청 체크리스트**

| 항목 | 확인 |
|------|------|
| URL 정확히 복사 | ✅ |
| serviceKey 삽입 | ✅ |
| params 딕셔너리 사용 | ✅ |
| timeout 설정 | ✅ |
| status_code 200 확인 | ✅ |
| JSON 응답 여부 확인 | ✅ |

## 2️⃣ JSON 응답 구조 파악

```python
data = res.json()

print(type(data))     # <class 'dict'>
print(data.keys())    # dict_keys(['currentCount', 'data', 'matchCount', 'page', 'perPage', 'totalCount'])
```

응답 최상위는 `dict`이고, 실제 측정 데이터는 `data['data']` 키 안에 **list** 형태로 들어 있습니다.

```
data (dict)
└── 'data' (list)
    ├── [0] → {'기온': 12, '도로명': '황금1로80번길', '습도': 60, '지역': '경기', ...}
    ├── [1] → {'기온': 13, '도로명': '황금로', '습도': 59, '지역': '경기', ...}
    └── ...
```

## 3️⃣ for문으로 DataFrame 만들기

### 방법 A — 전체 컬럼 다 가져오기

```python
rows = []

for i in data['data']:
    rows.append(i)          # dict 전체를 그대로 추가

df = pd.DataFrame(rows)
df
```

→ 기온, 도로명, 습도, 시작점, 오염범례 등 **모든 컬럼** 포함

---

### 방법 B — 원하는 컬럼만 인덱싱해서 가져오기 ⭐

```python
rows = []

for i in data['data']:
    rows.append({
        '지역': i['지역'],
        '도로명': i['도로명'],
        '습도': i['습도']
    })

df = pd.DataFrame(rows)
df
```

**흐름 설명:**

```
data['data']       →  list (10개 측정 행)
    i              →  list 안의 dict 하나 (측정 1건)
    i['지역']      →  그 dict에서 '지역' key의 value만 추출
    rows.append({}) →  원하는 key만 골라 새 dict로 만들어 추가
pd.DataFrame(rows) →  rows 리스트를 한 번에 DataFrame으로 변환
```

## 5️⃣ 핵심 포인트 정리

```python
# ❌ 이렇게 하면 안 됨 — append에 여러 값을 바로 넣을 수 없음
rows.append(i['지역'], i['도로명'], i['습도'])

# ✅ 이렇게 해야 함 — dict {} 로 감싸서 col명:value 형태로
rows.append({'지역': i['지역'], '도로명': i['도로명'], '습도': i['습도']})
```

> **팁**: 나중에 컬럼을 추가하고 싶으면 `rows.append({...})` 안에 키-값 쌍만 추가하면 됩니다.

---

## 📚 오늘 사용한 주요 함수

| 함수 | 역할 |
|------|------|
| `requests.get(url, params, timeout)` | HTTP GET 요청 |
| `res.json()` | JSON 응답 → dict 파싱 |
| `data['key']` | dict 인덱싱 |
| `list.append(dict)` | 리스트에 dict 추가 |
| `pd.DataFrame(rows)` | list of dicts → DataFrame |
