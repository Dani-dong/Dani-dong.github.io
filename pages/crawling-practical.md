# 💼 실전! 사람인 채용공고 완전 공략
## 데이터 분석 채용 트렌드 파악하기

기초를 배웠다면 이제는 실제 웹사이트를 대상으로 데이터를 수집해 볼 차례입니다. 이번 포스팅에서는 국내 대표 채용 포털인 **사람인(Saramin)**에서 '데이터 분석' 관련 공고를 자동으로 수집하고 분석하는 과정을 소개합니다.

---

## 1. 크롤러의 첫 에티켓: `robots.txt`와 Headers

무작정 데이터를 긁어오기 전에 사이트의 크롤링 정책을 확인해야 합니다. 또한, 자동화된 프로그램임을 숨기고 정상적인 브라우저 접근처럼 보이기 위해 `User-Agent`를 설정하는 것이 중요합니다.

```python
HEADERS = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/120.0.0.0'
}
response = requests.get(url, headers=HEADERS)
```

## 4. 데이터 분석 결과

수집한 데이터를 바탕으로 간단한 분석을 진행해 보았습니다.

- **지역별 분포**: 역시나 **서울 강남구, 서초구** 지역에 공고가 집중되어 있음을 확인할 수 있었습니다.
- **경력 요구사항**: '경력무관'과 '신입' 공고가 전체의 약 30%를 차지하며, 진입 장벽이 아주 높지만은 않다는 희망적인 결과가 나왔습니다!
- **기술 스택 트렌드**: 공고 제목에서 가장 많이 언급된 키워드는 **Python, SQL, Tableau** 순이었습니다.
